# Case Study: Testing a Linux System Information Script

## Overview

As part of my beginner Bash scripting practice, I created a script that displays basic Linux system information.

## Objective

Verify that the script correctly retrieves and displays:

- Operating system information
- Kernel version
- System uptime
- Memory usage
- Disk usage

## Environment

- Operating System: Void Linux
- Shell: Bash
- Script: `system-info.sh`

## Testing Process

1. Made the script executable using `chmod +x`.
2. Executed it from the terminal.
3. Checked each displayed section.
4. Confirmed that the script finished without errors.

## Results

All five information sections displayed successfully.

The script completed execution without reporting errors.

## What I Learned

- How Bash scripts execute on Linux.
- How to retrieve system information using standard commands.
- How to test a script in a real Linux environment.
- Why testing is important before sharing software.
