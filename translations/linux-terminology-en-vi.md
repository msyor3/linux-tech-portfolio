# Linux Terminology: English to Vietnamese

A small translation sample created as part of my beginner technical-writing portfolio.

I'm learning Linux and technical translation, with a focus on making technical concepts easier for Vietnamese readers to understand.

| English | Vietnamese |
|---|---|
| Operating System | Hệ điều hành |
| Kernel | Nhân hệ điều hành |
| File System | Hệ thống tập tin |
| Command Line | Dòng lệnh |
| Terminal | Trình dòng lệnh |

## Translation Example

**English:**

Linux is an open-source operating system kernel that manages hardware resources and allows software to interact with computer hardware.

**Vietnamese:**

Linux là một nhân hệ điều hành mã nguồn mở, có nhiệm vụ quản lý tài nguyên phần cứng và cho phép phần mềm tương tác với phần cứng máy tính.
